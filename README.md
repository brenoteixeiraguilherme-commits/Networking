# Porsche — Premium Concept Portfolio

Portfólio conceitual e não oficial inspirado na Porsche, desenvolvido com React, TypeScript, Vite e Tailwind CSS.

## Executar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Deploy na Vercel

- Importe este repositório: `brenoteixeiraguilherme-commits/Networking`
- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: `./`

O repositório usa a branch `main`. A publicação na Vercel deve ser feita pelo proprietário da conta, após conferir as configurações do projeto.

Este é um projeto conceitual independente e não é afiliado, patrocinado ou aprovado pela Porsche AG.
